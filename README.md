# Materials Science and Engineering

**Structure, Thermodynamics, Kinetics, Properties, Processing and Design**

The whole materials discipline in one book: why materials have the structures they have, how thermodynamics and kinetics set those structures, how structure produces properties, and how materials are processed, characterized, modelled, selected and kept in service. Parts VI and VII treat electrical, dielectric, magnetic, superconducting, semiconductor and photonic materials at the depth an electrical and electronic engineer needs.

**Read the book as a PDF:** [`pdf/Materials-Science-and-Engineering.pdf`](pdf/Materials-Science-and-Engineering.pdf)

## Build the PDF

Requires Node.js ≥ 18 and a local Chrome, Edge or Chromium (set `CHROME_PATH` if it is not found automatically).

```bash
npm install
```

```bash
npm run pdf
```

This writes `dist/Materials-Science-and-Engineering.pdf`. Build selected part openers or chapters with:

```bash
node scripts/build-pdf.mjs --parts P7,31,32 --out dist/excerpt.pdf
```

## Figures

Every figure is specified by a `<!-- FIGURE ... -->` marker at the point it belongs and drawn by `figures/scripts/chNN.py` (Python 3 with numpy, scipy and matplotlib).

```bash
npm run figures
```

```bash
node scripts/insert-figures.mjs
```

```bash
npm run figures:plan
```
